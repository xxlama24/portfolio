AI Malware Detection System

Graduation project · Taibah University · Team of five

Disguised malware slips past traditional antivirus tools. We built an AI system that checks whether a file is harmful and, if it is, names the malware family it belongs to. Users upload a file on a web page and get a clear report they can export as PDF.

  • 97.86%accuracy naming the malware family (25 families)
  • 94%of harmful files caught
  • 359,450images used to train and test

Registered as protected intellectual property with the Saudi Authority for Intellectual Property (SAIP). My supervisor reports it earned one of the highest grades among that year's graduation projects.
